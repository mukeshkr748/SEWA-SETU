# Sewa Setu — Civic Complaint Portal

Sewa Setu is a web-based civic complaint reporting application that allows users to register local issues and view submitted complaints.

## Features

* Register civic complaints through a web form.
* Store complaint records in an SQLite database.
* View registered complaints through an API.
* Health-check endpoint for application monitoring.
* Containerized deployment using Docker.
* Cloud deployment using AWS Elastic Beanstalk.

## Technology Stack

* **Language:** Python
* **Framework:** FastAPI
* **Frontend:** HTML, CSS, JavaScript
* **Database:** SQLite
* **Containerization:** Docker
* **Cloud Platform:** AWS Elastic Beanstalk
